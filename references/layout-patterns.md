# Slide Layout Patterns

Reference guide for selecting and structuring slide layouts.

## Title Slide
**Purpose:** Opening, deck identification
**Structure:**
- Title (large, centered or left-aligned)
- Subtitle (smaller, supporting)
- Presenter name, date, company logo

**Best for:** Every deck's first slide

---

## Agenda / Roadmap
**Purpose:** Preview structure, set expectations
**Structure:**
- Section names or numbered items
- Optional: timeline or progress indicator

**Best for:** Decks longer than 8 slides

---

## Section Divider
**Purpose:** Transition between major sections
**Structure:**
- Large section number or name
- Minimal text
- Bold visual or color block

**Best for:** Multi-section decks, helping audience track progress

---

## Single Big Idea
**Purpose:** Maximum impact for one key message
**Structure:**
- One powerful statement (large type)
- Supporting visual or icon
- Optional: small attribution or source

**Best for:** Key takeaways, quotes, compelling statistics

---

## Bullet List
**Purpose:** Multiple related points
**Structure:**
- 3-5 bullets
- Parallel structure
- Progressive logic (general → specific, or chronological)

**Best for:** Features, benefits, recommendations, steps

---

## Two-Column
**Purpose:** Comparison or related information
**Structure:**
- Left column header + content
- Right column header + content
- Clear visual separation

**Best for:** Pros/cons, before/after, compare/contrast, problem/solution

---

## Three-Column
**Purpose:** Three related items of equal weight
**Structure:**
- Three equal sections
- Consistent formatting per column
- Optional: icon per column

**Best for:** Three pillars, product tiers, key benefits

---

## Process / Steps
**Purpose:** Show sequence or workflow
**Structure:**
- Numbered or arrow-connected steps
- 3-5 steps optimal
- Optional: description per step

**Best for:** Methodology, implementation, customer journey, how it works

---

## Timeline
**Purpose:** Show chronology or milestones
**Structure:**
- Horizontal or vertical line
- Date markers with events
- Optional: phase groupings

**Best for:** History, project roadmap, rollout plan, past-to-future narrative

---

## Data / Chart
**Purpose:** Display quantitative information
**Structure:**
- Chart (takes 60-80% of slide)
- Clear title explaining insight
- Optional: brief annotation or takeaway

**Best for:** Metrics, trends, comparisons, survey results

---

## Dashboard / Metrics
**Purpose:** Multiple KPIs at a glance
**Structure:**
- 3-6 metric cards or blocks
- Large numbers with labels
- Optional: trend indicators (up/down arrows)

**Best for:** Performance reviews, status updates, executive summaries

---

## Comparison Table
**Purpose:** Detailed side-by-side comparison
**Structure:**
- Header row with column labels
- Rows for each attribute
- Checkmarks or values for comparison

**Best for:** Product comparison, feature matrices, vendor evaluation

---

## Quote / Testimonial
**Purpose:** Social proof or expert endorsement
**Structure:**
- Large quotation text
- Attribution (name, title, company)
- Optional: headshot or company logo

**Best for:** Customer testimonials, expert quotes, credibility building

---

## Case Study
**Purpose:** Story-based proof point
**Structure:**
- Client/Company name
- Challenge → Solution → Results
- Metrics or outcomes
- Optional: quote

**Best for:** Sales decks, credibility, showing real-world application

---

## Architecture / Diagram
**Purpose:** Show system, structure, or relationships
**Structure:**
- Central diagram or flowchart
- Clear labels
- Legend if needed

**Best for:** Technical presentations, organizational structure, system design

---

## Team / Contributors
**Purpose:** Introduce people
**Structure:**
- Headshots with names and titles
- Optional: brief bio or role description
- Consistent formatting

**Best for:** Investor pitches, project kickoffs, about us sections

---

## Summary / Key Takeaways
**Purpose:** Reinforce main points
**Structure:**
- 3-5 bullets summarizing deck
- Consistent with earlier messaging
- Optional: visual reinforcement

**Best for:** Closing before Q&A, ensuring retention

---

## Next Steps / CTA
**Purpose:** Drive action
**Structure:**
- Clear action items or decision needed
- Owner and timeline if applicable
- Contact information or resources

**Best for:** Final slide, proposal closes, project kickoffs

---

## Thank You / Q&A
**Purpose:** Signal conclusion, invite questions
**Structure:**
- Thank you message
- Presenter contact info
- Optional: QR code or resource link

**Best for:** Every deck's final slide

---

## Appendix
**Purpose:** Supporting detail (not presented live)
**Structure:**
- Detailed data
- Backup slides
- Methodology or sources

**Best for:** Reference material, answering detailed questions
