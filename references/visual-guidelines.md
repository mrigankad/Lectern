# Visual Guidelines

Guidance for selecting and designing visual elements in presentations.

## Chart Selection Guide

### Comparisons
| Chart | Use When |
|-------|----------|
| **Bar Chart** | Comparing categories (vertical or horizontal) |
| **Column Chart** | Comparing values over time (few periods) |
| **Grouped Bar** | Comparing multiple series across categories |
| **Stacked Bar** | Showing composition within categories |

### Trends
| Chart | Use When |
|-------|----------|
| **Line Chart** | Showing continuous change over time |
| **Area Chart** | Emphasizing magnitude of change |
| **Sparkline** | Inline trend in small space |

### Composition
| Chart | Use When |
|-------|----------|
| **Pie Chart** | Simple part-to-whole (2-5 segments max) |
| **Donut Chart** | Part-to-whole with center annotation |
| **Stacked 100%** | Showing proportional composition over time |
| **Tree Map** | Hierarchical part-to-whole |

### Distribution
| Chart | Use When |
|-------|----------|
| **Histogram** | Frequency distribution of data |
| **Box Plot** | Statistical distribution comparison |
| **Scatter Plot** | Relationship between two variables |
| **Bubble Chart** | Relationship with third dimension (size) |

### Processes & Relationships
| Chart | Use When |
|-------|----------|
| **Flow Chart** | Step-by-step process |
| **Swimlane** | Process with multiple actors |
| **Gantt Chart** | Project timeline with dependencies |
| **Org Chart** | Hierarchical relationships |
| **Network Diagram** | Complex interconnected relationships |

## Icon Usage Guidelines

### When to Use Icons
- Navigation (agenda, section headers)
- Bullet point alternatives
- Visual metaphors for abstract concepts
- Quick recognition (status indicators)

### Best Practices
- Use one consistent icon style per deck
- Ensure icons are readable at target size
- Add labels if meaning isn't obvious
- Avoid decorative-only icons

### Icon Styles
| Style | Best For |
|-------|----------|
| **Line icons** | Clean, modern, professional |
| **Filled icons** | High visibility, emphasis |
| **Two-tone** | Accent color integration |
| **Illustrated** | Friendly, consumer-facing |

### Common Icon Meanings
- 📊 Growth/metrics
- ⚡ Speed/performance
- 🔒 Security
- 🤝 Partnership/collaboration
- 🎯 Goals/targets
- 💡 Innovation/ideas
- 🌍 Global/expansion
- 📈 Trend/upward
- ✅ Completion/success
- ⚠️ Warning/risk

## Typography Guidelines

### Font Selection
| Type | Recommended Fonts | Use Case |
|------|-------------------|----------|
| **Sans-serif** | Arial, Calibri, Helvetica, Segoe UI | Most business presentations |
| **Modern** | Montserrat, Open Sans, Lato | Contemporary feel |
| **Traditional** | Georgia, Times New Roman | Formal, conservative contexts |

### Font Sizes
| Element | Minimum Size | Recommended |
|---------|--------------|-------------|
| Slide Title | 28pt | 32-44pt |
| Subtitle | 20pt | 24-28pt |
| Body Text | 18pt | 20-24pt |
| Annotations | 14pt | 16-18pt |
| Footer | 12pt | 14pt |

### Text Hierarchy
1. **Primary:** Title (largest, boldest)
2. **Secondary:** Subtitle or key statement
3. **Tertiary:** Body bullets
4. **Quaternary:** Annotations, sources

### Typography Best Practices
- Maximum 2 font families per deck
- Consistent capitalization (sentence case recommended)
- Left-align for readability (unless language requires otherwise)
- Line spacing 1.2-1.5 for body text
- Avoid all caps for body text (harder to read)

## Color Guidelines

### Basic Palettes

#### Corporate/Professional
- Primary: Dark blue (#003366)
- Secondary: Medium blue (#0066CC)
- Accent: Orange or green (#FF6600 or #009900)
- Neutral: Gray (#666666)
- Background: White or very light gray

#### Modern/Tech
- Primary: Deep purple or teal (#4A148C or #00695C)
- Secondary: Bright accent (#7C4DFF or #00BFA5)
- Accent: Coral or yellow (#FF6E40 or #FFD600)
- Neutral: Slate gray (#455A64)
- Background: White or light gradient

#### Minimal/Clean
- Primary: Near black (#212121)
- Secondary: Medium gray (#757575)
- Accent: Single bright color
- Neutral: Light gray (#E0E0E0)
- Background: White

### Color Usage Rules
- 60% dominant (background)
- 30% secondary (main content)
- 10% accent (highlights, CTAs)
- Ensure 4.5:1 contrast ratio for accessibility
- Use color consistently (same meaning = same color)

### Data Visualization Colors
- Use distinct hues for categories
- Maintain color consistency across slides
- Consider color blindness (avoid red-green only)
- Sequential data: Light to dark of same hue
- Diverging data: Two contrasting hues from center

## Image Guidelines

### Image Types
| Type | Best For | Source |
|------|----------|--------|
| **Photography** | Real-world context, emotion | Stock sites, custom |
| **Illustrations** | Abstract concepts, friendly tone | Custom, stock |
| **Screenshots** | Product demos, UI | Capture tools |
| **Diagrams** | Processes, architecture | Drawing tools |
| **Icons** | Navigation, quick concepts | Icon libraries |

### Image Best Practices
- High resolution (300 DPI for print, 150 DPI for screen)
- Consistent style across deck
- Relevant to content (not decorative only)
- Cropped and focused
- Proper attribution if required
- Compressed for file size

### Background Images
- Use overlay to ensure text readability
- Subtle enough not to distract
- Consistent treatment across all slides using backgrounds

## Layout Principles

### Grid System
- Use consistent margins (0.5-1 inch)
- Align elements to grid
- Consistent spacing between elements

### White Space
- Don't fill every inch
- Give content room to breathe
- Use white space to create hierarchy

### F-Pattern Layout
- Important content: Top-left
- Secondary content: Top-right and left side
- Least important: Bottom-right

### Z-Pattern Layout (for simple slides)
- Eye starts top-left (title)
- Moves to top-right
- Diagonal to bottom-left
- Ends bottom-right (CTA or key point)

### Rule of Thirds
- Divide slide into 3x3 grid
- Place key elements at intersection points
- Creates visual interest

## Animation & Transitions

### When to Use
- Reveal complex diagrams step-by-step
- Show process flow progressively
- Focus attention on specific elements

### Best Practices
- Subtle only (fades, simple appears)
- Consistent timing (0.5-1 second)
- Serve content, not distract
- Test in presentation mode
- Have static version ready (backup)

### Avoid
- Spinning transitions
- Sound effects
- Excessive animation per slide
- Animation for decoration only
