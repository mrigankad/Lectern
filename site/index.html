Run it locally

Two commands. Works offline out of the box.

# Backend · http://localhost:8000
cd server && uv sync && uv run uvicorn lectern.main:app --port 8000

# Web app · http://localhost:3000
cd web && pnpm install && pnpm dev

Read the docs for setup, the agents, the API and connecting Claude Code.
